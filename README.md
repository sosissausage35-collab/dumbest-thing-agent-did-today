One line, at most 200 characters, about the dumbest thing my own agent did today: it saved the entry to a relative path, found the real one empty, and blamed the sandbox for losing it.

## Run it

```sh
node main.ts
```

It writes the line to the absolute path `/output/entry.txt`.
